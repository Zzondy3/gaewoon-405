# 📈 그래프 투자 교실

꺾은선 그래프를 해석해서 두 기업 중 어디에 얼마나 투자할지 모둠별로 정하는 수업용 모의 투자 프로그램입니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 학생 화면 | 사이트 첫 화면 `/` | 모둠별 디벗(태블릿) |
| 선생님 화면 | `/teacher.html` (비밀번호 기본 `1234`) | 선생님 PC — 학생 화면에는 링크가 없어요 |

선생님 화면 주소를 바꾸려면 `app/teacher.html` 폴더 이름을 원하는 이름으로 바꾸면 됩니다.

## 수업 흐름
1. 학생: 사이트 첫 화면에서 모둠(1~5모둠) 선택 → "앞 화면(PPT)을 봐 주세요" 대기 화면
2. 선생님: PPT로 그래프·기업 자료 설명 → **▶ 투자 시작**
3. 학생: A·B 기업에 투자할 코인 + **투자 이유** 입력 → 제출 ("이렇게 투자하시겠습니까?" 확인, 마감 전까지 수정 가능)
4. 선생님 화면에 제출 현황과 투자 이유가 실시간으로 표시
5. **■ 투자 마감**(누르면 바로 결과 공개) → 바로 학생 화면에 코인 변화 반영, PPT로 결과 설명
   (실수했으면 **↩ 결과 공개 취소** → 다시 투자 중 상태)
6. **다음 라운드 ▶** (마지막 라운드 뒤에는 최종 순위)

- **⏭ 라운드 건너뛰기**: 결과를 반영하지 않고 다음 라운드로 (대기·투자 중 상태에서 가능)
- **실시간 순위**: 학생 화면 아래쪽과 선생님 화면에 항상 표시
- 계산: `결과 코인 = 원래 코인 + A기업 변화 + B기업 변화`
  - 2배 획득: 100 투자 → +200 / 잃기: 100 투자 → -100 / 절반 잃기: 100 투자 → -50
  - 보너스는 그 기업에 1코인 이상 투자한 모둠만 받음
  - 미제출 모둠은 코인 그대로
  - 코인이 0이 된 모둠은 더 이상 투자할 수 없음 (선생님이 '모둠 코인 직접 수정'으로 코인을 주면 다시 참여 가능)

## 라운드 바꾸기
`lib/scenarios.js` 하나만 고치면 됩니다. 기업 이름과 결과(`gain`, `bonus`)만 적으면 설명 문구는 자동으로 만들어져요.
결과는 서버에만 있어서 공개 전에는 학생 기기로 볼 수 없습니다.

## 내 컴퓨터에서 실행 (VS Code)
```bash
npm install
npm run dev
```
→ 학생 http://localhost:3000 , 선생님 http://localhost:3000/teacher.html . 이때는 저장소 없이 메모리에 저장됩니다(서버를 끄면 초기화).

## Vercel 배포 (처음 한 번)
1. 이 폴더를 GitHub 저장소에 올리기 (push)
2. vercel.com → **Add New → Project** → 그 저장소 Import → Deploy
3. 프로젝트 → **Storage** 탭 → **Upstash for Redis**(Marketplace) 만들기 → 이 프로젝트에 Connect
   (환경변수 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 이 자동으로 추가됨)
4. (권장) **Settings → Environment Variables** 에 `TEACHER_PIN` = 원하는 비밀번호 추가
5. **Deployments → Redeploy** 한 번 (환경변수 적용)

> Redis를 연결하지 않으면 선생님 화면에 노란 경고가 뜹니다. Vercel에서는 서버가 여러 개로 나뉘어 돌기 때문에 꼭 연결해야 제출 내용이 사라지지 않아요.

이후에는 GitHub에 push 할 때마다 Vercel이 자동으로 다시 배포합니다.

## 폴더 구조
```
lib/scenarios.js     문제(시나리오) ← 주로 여기만 수정
lib/game.js          결과 계산
lib/store.js         저장소 (Redis / 메모리)
app/page.js          학생 화면 (첫 화면)
app/teacher.html/page.js  선생님 화면
app/api/*            서버 API
```
